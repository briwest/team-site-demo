# Team Site Showcase 🚀

A modern, high-performance interactive team showcase website built with HTML5, CSS3, and modern Vanilla JavaScript.

## Features ✨
### Other Features

- **Glassmorphic UI Design**: Dark/light mode theme toggle, vibrant ambient glow backdrop, and responsive CSS grid layout.
- **Interactive Directory**: Search team members by name, role, or tech stack keywords.
- **Department Filtering**: Filter team cards by Leadership, Engineering, Design, or Product.
- **Member Detail Modals**: View impact stats (Projects led, GitHub contributions) and core competencies.
- **Add Teammate Form**: Dynamic client-side nomination/onboarding form with real-time feedback toast notifications.
- **Key Metrics Counters**: Highlighting team scale, deployed projects, git commits, and SLA uptime.

## Structure 📁

- `index.html` - Semantic HTML5 layout and modal overlays
- `styles.css` - Full CSS design system and responsive styles
- `app.js` - Dynamic filtering, search, modal state management, and theme switcher
- `calculator.py` - Core Python utility function module

## Running Locally 💻

Open `index.html` directly in any web browser, or serve using Python:

```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.
